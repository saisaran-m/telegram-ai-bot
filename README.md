\# 🤖 Telegram AI Bot



A free, fast AI assistant bot for Telegram powered by \*\*Groq\*\* and \*\*LLaMA 3.3\*\*.



\## ✨ Features

\- 💬 Answers any question instantly

\- 🧠 Remembers conversation history

\- ⚡ Super fast responses via Groq

\- 🆓 Completely free to use

\- 🌍 Works worldwide



\## 🛠️ Built With

\- Python 3.10+

\- python-telegram-bot

\- Groq API (LLaMA 3.3)



\## 🚀 Setup



1\. Clone the repo

2\. Install dependencies:

&#x20;  pip install python-telegram-bot groq

3\. Set your keys:

&#x20;  set TELEGRAM\_TOKEN=your\_token

&#x20;  set GROQ\_API\_KEY=your\_groq\_key

4\. Run:

&#x20;  python bot.py



\## 📌 Commands

| Command | Description |

|---------|-------------|

| /start  | Start the bot \& clear history |

| /clear  | Clear conversation history |

| /help   | Show help message |
