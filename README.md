# 🤖 Telegram AI Bot

A free, fast AI assistant bot for Telegram powered by **Groq** and **LLaMA 3.3**.

## ✨ Features
- 💬 Answers any question instantly
- 🧠 Remembers conversation history
- ⚡ Super fast responses via Groq
- 🆓 Completely free to use
- 🌍 Works worldwide

## 🛠️ Built With
- Python 3.10+
- python-telegram-bot
- Groq API (LLaMA 3.3)

## 🚀 Setup

1. Clone the repo
2. Install dependencies:
   pip install python-telegram-bot groq
3. Set your keys:
   set TELEGRAM_TOKEN=your_token
   set GROQ_API_KEY=your_groq_key
4. Run:
   python bot.py

## 📌 Commands
| Command | Description |
|---------|-------------|
| /start  | Start the bot & clear history |
| /clear  | Clear conversation history |
| /help   | Show help message |
